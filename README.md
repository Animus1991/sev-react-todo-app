# sev-react-todo-app

Todo list SPA built with React 19, TypeScript, and Vite. Uses Tailwind CSS for styling and local storage for persisting tasks.

## Tech stack

- **React 19** · **TypeScript** · **Vite 7**
- **Tailwind CSS** · **Lucide React** (icons)

## Requirements

- Node.js 18+
- npm or pnpm

## Setup & run

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Scripts

| Command         | Description              |
|-----------------|--------------------------|
| `npm run dev`   | Start dev server (HMR)   |
| `npm run build` | Production build        |
| `npm run preview` | Preview production build |
| `npm run lint`  | Run ESLint               |
